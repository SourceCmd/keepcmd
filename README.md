# Keep Cmd

Signed releases of Keep Cmd (`keepcmd`), the program that turns a computer of
yours into a keep for Loop Cmd and Hearth Cmd, published at
https://get.keepcmd.com (the website is https://keepcmd.com, D-406). Binaries only; the source isn't public.

- `releases/`: the signed release feed (`latest.json`) and binaries.
- `blueprints/`: the signed blueprints catalog (`index.json`, `index.json.sig`, `catalog.tar.gz`), built from [SourceCmd/blueprints](https://github.com/SourceCmd/blueprints).
